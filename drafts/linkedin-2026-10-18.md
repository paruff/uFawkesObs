Our own observability stack fired 27 alerts on a perfectly healthy install.

That is worse than it sounds. An install that alerts on itself trains you to
ignore alerts, and the first one you ignore is the real one.

uFawkesObs v1.0.1 fixes it at the source. A service that was never meant to run
by default is no longer scraped. A restart alert stopped counting a one-second
clock wobble from Docker Desktop. Alerts that watched metrics nobody exports
now watch ones that exist. Fresh install, 30 minutes, zero alerts, on Linux and
macOS.

Quiet by default is a feature. https://github.com/paruff/uFawkesObs
